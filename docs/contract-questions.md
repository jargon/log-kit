# Contract questions

Append questions here instead of guessing. The `spec-keeper` writes proposals; a human approves.

Status values: `open` → `proposed` → `approved` → `applied` (or `rejected`).

## Template

```
### Q<n>. <short title>
Status: open
Raised by: <agent or person>, <date>
Rules: C<x.y>
Context: what you were doing and what is unclear.
Reading A: …
Reading B: …
Suggested answer: …

Proposal (spec-keeper):
Before: …
After: …
Affected tests/tasks: …
```
